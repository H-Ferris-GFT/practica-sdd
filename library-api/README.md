# Library API

API backend minima en Spring Boot para el ejemplo SDD de gestion de libros de biblioteca.

## Requisitos

- Java 17
- Maven 3.9 o superior

## Comandos

Ejecutar tests:

```bash
mvn test
```

Arrancar la aplicacion:

```bash
mvn spring-boot:run
```

Generar el paquete:

```bash
mvn package
```

## Estructura

- `src/main/java`: codigo de la aplicacion.
- `src/test/java`: tests automatizados.
- `pom.xml`: configuracion Maven del servicio.
- `target`: salida generada por Maven.
